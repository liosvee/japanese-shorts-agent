# Bilingual original script and storyboard

## Use the active learning run

For a new production, follow [the shared learning workflow](../evolution/WORKFLOW.md) after intake establishes the niche. Read the active run's brief before drafting. Prepare an original script, thumbnail plan, hashtags, tags, description and storyboard, addressing the applicable rules for all six facets. Apply the findings with an artifact-bound receipt and verify before narration, paid media or render commands. After retiming or revising bound artifacts, re-apply and verify; preserve existing approvals. A resumed production uses its existing research run. Unavailable observations remain explicit gaps.


When running research-next-video, the coordinator first exports the selected
topic with `python -m jp_shorts.agent_brief PROJECT` and issues the writer
packet described in the [handoff protocol](../.claude/skills/research-next-video/protocol/packets.md).
Receive and inspect the actual script before issuing the editor packet. Bind
both packets in the native application receipt before production.

Create script.ja.txt, script.en.txt, storyboard.json, claims.json and packaging.md
inside the project. Use templates/storyboard.json and templates/claims.json.

- One clear promise, a compelling factual hook, concise development, and a
  satisfying answer. Curiosity must be paid off; no misleading claims.
- Natural spoken Japanese with an accurate English translation. Avoid unnatural
  literal translations, unsupported superlatives and culturally stereotyped copy.
- A fresh angle and examples distinct from reference videos. Document the
  originality differences in reference-analysis.md.
- A light next-video invitation only when it fits the subject; do not withhold
  the promised answer to force another watch.
- Verify every substantive factual assertion and mark uncertainty explicitly.
  Remove unsupported claims before approval. High-stakes topics need appropriate
  primary sourcing and careful scope.
- Plan 30–60 seconds initially. Label duration as estimated until narration is
  measured. Do not infer Japanese speaking time from English word count.
- Specify new/generated/licensed assets, provenance and intended use per scene.
- Provide Japanese title, English title, Japanese description and relevant tags;
  avoid claims that packaging guarantees a particular click rate.

Present the full Japanese script, English translation, storyboard and factual
sources. Inspect the actual available voices/models. Prepare the exact paid
plans and source-dated total estimate, then ask for approval. Do not generate
paid narration merely to estimate its duration. Reuse existing approval if it
clearly covers the final content and cost.
